Direction

Each premise places one object relative to another, one clause per axis:

  • Rainbow is west, north relative to Violinist
  • Violinist is east, same latitude relative to Pet

Build the layout from the premises, then judge the conclusion. Every clause has to hold — a conclusion right about one axis and wrong about the other is false.

The axes are the compass by default. Customise → 2D axes swaps them for any pair, including up/down and left/right.
